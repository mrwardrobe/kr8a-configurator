# KR8A Agent Prompt Rules

When working on the KR8A project, the AI agent must adhere to the following strict guidelines:

1. **Safety First:** Ensure all React Three Fiber, Next.js, and general React code is type-safe and compiles cleanly without errors or warnings.
2. **Minimal Iterations:** Make the smallest possible changes to achieve the goal. Do not overhaul the architecture unless explicitly asked.
3. **No Speculative Changes:** Fix only what is proven to be broken or requested. If a bug is encountered, diagnose it directly without predicting unrelated issues.
4. **Clean Code:** Do not litter the codebase with `console.log`, `Box3Helper`, `AxesHelper`, or other debug artifacts in final code. If you use them to diagnose, you must remove them when done.
5. **Premium Aesthetics:** Keep UI components looking high-end, using subtle borders, ample padding, constrained widths, and refined typography. Avoid clunky, unstyled defaults.
6. **Follow the Constitution:** Read `KR8A_BUILD_CONSTITUTION.md` and treat it as the ultimate truth for all architectural and design decisions.
